⌘K in every app

As built, 2026-11-27 · shaped 2026-11-20 · Ship project · Goal: ⌘K opens the same box in Peek, Leaf and Ship: a name finds anything, a sentence asks about what is open, and the box suggests what to do with it.

Today the ⌘K box and everything it knows live inside Peek. This project moves that into one shared piece that Peek, Leaf and Ship all mount, each handing it what is open. The browser's own model gains a second job: guessing which action a sentence wants. Nothing the relay stores or checks changes.
