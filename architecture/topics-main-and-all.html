Topics: Main and All

As built, 2026-11-10 · shaped 2026-11-06 · Ship project · Goal: in Peek, a topic you follow at All shows what is said on every file it lists, each thread under its file's name.

Nothing new is written to the relay. Peek already read a topic's list of files and a topic's own conversation ("Today", kept as the history). As built, the shared package reads the conversations of every listed file in one go and keeps them live, and the shared conversation puts a file's icon and name above each of its threads. Your level on the topic decides which you see. One change was not foreseen when the project was shaped: listed files sit in many teams, so instead of naming each team, a live request now asks by file alone, and the relay sends it every new event its reader may read, as asking again would. Look first at the Flow: a comment written in Leaf reaches the topic in Peek, and a reply from Peek lands back on the page.

Objects and access

Unchanged. A topic lists files by id. A comment belongs to its file and a new one is kept in that file's team, so the relay lets only that team's readers read it; an older comment may sit in a team that lists the file (SPEC §6.4). Following at All grants nothing and makes nobody a member of a listed file. A live request that names no team is checked at delivery against the same teams a stored read would answer from, so asking by file alone shows nobody more than asking again would. Nothing is private today; what All shows for a file you cannot open is decided with private teams.
