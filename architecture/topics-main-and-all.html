Topics: Main and All

Shaped, 2026-11-06 · Ship project ·Goal: in Peek, a topic you follow at All shows what is said on every file it lists, each thread under its file's name.

Nothing new goes on the relay. Peek already reads a topic's list of files and a topic's own conversation. This project adds one read in the shared package, the conversations of every listed file, and a file's name above each of its threads in the shared conversation. Your level on the topic decides which you see. Look first at the Flow: a comment written in Leaf reaches the topic in Peek, and a reply from Peek lands back on the page.

Objects and access

Unchanged. A topic lists files by id. A comment belongs to its file and is kept in that file's team, so only the file's readers read it. Following at All grants nothing and makes nobody a member of a listed file. Nothing is private today; what All shows for a file you cannot open is decided with private teams.
