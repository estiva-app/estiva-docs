Move Ship onto the shared read

As built, 2026-11-23 · shaped 2026-11-20 · Ship project · Goal: Ship reads a project or an issue with the same code Peek, Leaf and the agent use, so there is no second read left to disagree with them. Follows Tests that try thousands of inputs.

Nothing a person uses changes. Before, the same changes to a project or an issue were turned into what you see by three pieces of code: Ship's own, the shared one, and the agent's rebuild of the history. As built, there is one, and it gives any app what only Ship's gave.
