Issues stop downloading every edit

Shaped, 2026-11-16 · Ship project · Stage 2 of "One current version of every file", after projects · Goal: a cold Ship load carries each issue as it is now, about 5 KB an issue, not the 25.6 MB of every edit ever made to one.

The relay already keeps every file type's changes in order; projects were the first type the apps use that for. This stage moves issues: Ship, Leaf, Peek and the agent stop downloading and replaying every issue change and read each issue as it is now, write each change after the one it follows, and a new issue's text becomes a change like any other. Look first at the Map: the relay barely changes, the apps do. It starts when "Each company sets its own statuses" closes and builds on that project's status writes.
