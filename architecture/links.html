Links

Shaped, 2026-11-24 · Goal: a file has one link, written and read the same way by Peek, Ship, Leaf and the agent, and the relay turns away a file that could not have one. · Follows Move Ship onto the shared read.

Today each app turns a file into a link with its own code, and two of them keep a second link shape for a file whose id is unusual. No such file exists, and after this project none can: the relay refuses it. The link is then written by one shared piece of code, the old shapes already in text are rewritten, and the code that read them goes. Look at the Map first, then the table of link shapes.

Who checks a file's id

File typeTodayAfter
A bare fileThe relay: a lowercase uuid, or refusedThe same
A topic, a page, a project, an issueNobody. Every app happens to make a uuidThe relay, on the first save (M1); the shared code that builds the file, before it is sent (M2)
A teamThe relay makes the id itselfThe same

This is a format rule, not who may read or write: an odd id gives nobody access to anything.
