The Journal in Ship, with Claude recording into it

Shaped, 2026-11-28 · Ship project · Goal: you open a project in Ship and read on its Journal tab what was decided and what happened since you last looked, written there by Claude's sessions and by people. Earlier page: Insights, Journal and Risks.

Today a Claude session writes what was decided and what happened as lines of text inside an issue's and a project's description. No app can list them, accept one or answer one. This project makes each a Journal entry: a highlight, a file of its own, whose word is Decision or Update. Highlight is one shared type, written here for the first time; the record that says so is written in this project's first issue. Claude writes entries with its own key, Ship lists a project's on a new Journal tab, and only the calls Claude made itself wait for a person. Marking a message or a block comes in a later project.
