Estiva is a set of apps for one team: Peek for chat, Ship for projects and issues, and Leaf for documents. They share one workspace, which is a single relay. Every app reads and writes the same signed events there, so a file made in one app can be found and discussed in the others.

Start with the first map, then look at Objects to see what a person meets. Flow follows one comment from Ship to Peek. Project pages redraw their parts from this page.

Access

Every read and every write is made by someone on the workspace, and every event is signed by the person who sent it. The rows below are the rules the relay, Estiva ID or each reading app enforces; a rule that is decided and still being built names its record and the issue that carries it out. Teams are open in this stage, so for an open team "whoever can read the team" is everyone on the workspace (SPEC §3.1). What a private team hides is not designed yet, so this table describes open teams. The protocol still calls a team a Folder.
