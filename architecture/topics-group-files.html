Topics group files

Shaped, 2026-10-30 · Ship project: Topics group files · Goal: a topic groups the files it is about, from any Folder, so Peek's Topics screen reads as a few topics with their files under them, and every file you joined, by Folder, moves to a Folders screen beside it.

Today only a Folder keeps a list of files, so Peek's Topics screen draws every file you joined, flat, under its Folder. After this project Peek has a new Topics screen of your topics, each with its files, and today's screen moves beside it as Folders; a topic keeps its own list: one entry per file, named by the file's id and signed by whoever added it. The file stays in its own Folder, where it keeps its place in the tree, and can be in many topics; through a topic the list is flat. Every app can ask the relay which topics list a file. The relay's rules do not change. Start with the Map.

Access

Unchanged, so there is no table. A topic's list is changes on the topic, so who may add or remove an entry is who may write in the topic's Folder, checked by the relay as for any change to a file (base page, "A file's title, summary, text and other fields"). Listing a file grants nobody anything: who can read a file stays its own Folder's, wherever it is listed (SPEC §3.1), as with a Folder's list. Nothing is private today.
