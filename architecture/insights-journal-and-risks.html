Insights, Journal and Risks

Shaped, 2026-11-16 · Ship project ·Goal: you mark a message in Peek, a block in Leaf or a comment in Ship, and it appears on the project's Insights, Journal or Risks tab in Ship.

Today what a team learns, decides and worries about has no home of its own: it sits in conversations, documents and our hand-kept notes. This project adds three shared types of file, an Insight, a Journal entry and a Risk: Osnova's memory layer, which any app's file can have. Each item is filed in one team, is about a file when it can be, and shows its source as it was marked. Peek, Leaf and Ship write them; Ship lists a project's in three new tabs.
