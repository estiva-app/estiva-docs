One conversation in every app

Shaped, 2026-10-28 · Ship project · Goal: a conversation looks and works the same in Peek, Ship and Leaf, as one shared piece each app places and colours.

Today each app draws its own comment cards, threads and menus around the shared comment box. After this project the conversation is one shared piece: each app only says where it sits, gives it the data, and colours it. Ship also joins the apps that resolve a thread. Nothing on the relay changes. Start with the Map.

Objects

Unchanged. A comment, a reply, an edit, a delete, a reaction and a resolve are the same events as today (SPEC §6.4, §6.6; KINDS.md). What changes is that every app reads them into one shape and draws them one way. A Highlight is not one of them: it has no shape on the relay, and this project does not give it one (Highlights on the relay).
